# The pinned toolchain, installed by `just setup` into ./.venv.
#
# Every *third-party linter* is a pre-commit hook pinned by `rev` in
# .pre-commit-config.yaml, in its own isolated environment — one pin per
# tool, in one place, and none of them shares this interpreter. What
# lives here is the hook runner itself, plus what this repository's own
# checks import. `just` itself is a system tool, installed per
# workstation like python3 and git, so `just setup` is the entry point
# with nothing before it.
pre-commit==4.4.0

# PyYAML, for scripts/check_frontmatter.py. Our own checks are not

# answering that needs a real YAML parser rather than a hand-rolled one
# (rule 11: the boring standard tool). It shares this interpreter
# because `.venv` is guaranteed wherever the checks run — pre-commit
# itself lives there.
